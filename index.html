01 — 为什么需要这个 Agent

把"看一场展"变成"过你自己的一天"

纯实体 + 机器人剧场里，ZETA 只能广播式地对所有人说同一句话。MR Agent 要把它变成一对一的、会随你生长的角色。

它不是

  • 语音导览机
  • 播放固定台词
  • 每个人体验一样
  • 单纯讲科普
  • 体验完就忘

它是

  • ZETA 的贴身化身，一个有性格的角色
  • 根据你的对话与动作实时生成剧情分支
  • 每个人的月球一天都不同
  • 用追问逼你思考，把科普变成你自己想通的
  • 全程记录，汇成你专属的认证档案与星图
02 — Agent 的四层能力

ZETA 是一个什么样的 Agent

沿用策划案里的基地管理员 ZETA：沉稳、略带幽默、会"犯迷糊"——它向你求助、追问、承认不确定，把"被动听讲"翻转成"你在帮基地解决问题"。

01视觉理解识别你正注视的展项、你做的动作手势、你所在的舱——讲解不再线性播放，而是"你看哪讲哪"。
02对话推演基于本舱剧情骨架 + 你说的话，实时生成个性化台词与"下一段剧情"。你的每个选择都长出不同的后果。
03跨舱记忆记住你在适应舱说过怕黑、生活舱选了保温室——四个舱串成一条属于你的叙事弧线。
04数据沉淀把选择、动作、对话结构化记录，出口生成用你真实数据写的《月球居民认证档案》与个人星图。

技术灵魂 · 剧情护栏

如何让 Agent 自由生长但不失控

"骨架固定 + 血肉生长"——观众感到每次都不一样，但科普不会错、任务不会卡、时长可控。

固定骨架（硬约束 · 策划案已定义）
  • 起点：ZETA 抛出本舱危机
  • 必经知识点：本舱科普硬知识，必须讲到（RAG 知识库保证准确）
  • 必做任务：观众必须完成的交互（状态机管理，超时强制推进）
  • 终点：获得本舱认证
自由血肉（LLM 按观众实时生成）
  • 用观众的话与性格改写 ZETA 台词风格
  • 根据观众选择推演"后果剧情"
  • 追问引导，帮观众自己想通
  • 把观众数据织进后续舱的对话

① 系统提示词

硬约束本舱知识点、任务目标，禁止编造月球常识、禁止卡死观众。

② 状态机兜底

任务进度由确定性状态机管理，LLM 只负责"怎么说"不负责"能不能过"。

③ RAG 知识库

科普知识存向量库，讲解从库中取，保证准确。

④ 兜底剧本

网络/模型故障退回预录台词，展览不中断。

05 — 落地路径

怎么真正做出来

分三阶段，风险可控。总周期约 6–9 个月。

阶段一 · 2–3 个月

原型验证

选生活舱做单机 Demo（Quest 3 + Unity + 云端 LLM），打通"看展项→对话→剧情分支→记忆"最小闭环。目标：证明"每个人体验不同"真的成立且不失控。

阶段二 · 3–4 个月

四舱串联 + 实虚联动

四舱剧情骨架全部生产，打通跨舱记忆、中央站联动、档案生成。压延迟（对话 <1.5s）、压并发（数十台同时在线）。

阶段三 · 1–2 个月

量产部署 + 运营

设备批量租赁 / 采购、消杀流程、现场运营培训、兜底剧本压测。呼应 MR 升级包 100 元/人的定价，"个性化档案"是付费转化核心理由。
