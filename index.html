01 — Agent 的四层能力

ZETA 是一个什么样的 Agent

沿用策划案里的基地管理员 ZETA：沉稳、略带幽默、会"犯迷糊"——它向你求助、追问、承认不确定，把"被动听讲"翻转成"你在帮基地解决问题"。它只用语言工作，不碰机器人和画面。

01进度感知知道你在哪个舱、预制剧情播到了哪一步——好在正确的时机开口，把话接到当前这段故事上。它不识别、也不驱动任何动作。
02故事延展在预制剧情的间隙或结尾，顺着你说的话，把这段故事往后多讲一段、抛出下一个问题，让固定剧情多一层随你生长的对话。
03追问科普你想深挖时随时追问，ZETA 从知识库里取准确内容答你；也会反过来追问你，帮你自己想通，把科普变成对话而非念稿。
04跨舱记忆记住你在前面舱聊过、选过什么，后面的对话接得上——四个舱的闲聊串成一条属于你的话头。
02 — Agent 怎么"出现"

Agent 在 MR 里长什么样

这里说的只是 ZETA 的视觉外观——它以什么形象陪着你说话。形象也是预制的动画，不代表它在控制现场设备。

形态 A · 主形态 🛰️

全息形象跟随

ZETA 以发光球体 / 悬浮机器人的形象出现在视野中，"飘"在你身边半米处，你转头它跟随。说话时有光态与粒子波动——一个会陪你聊天的形象，而不只是一个声音。

形态 B · 最出彩 ✨

实体 ↔ 虚拟 分身

入口看到实体 ZETA 机器人；戴上 MR 瞬间，一束数据流从实体机器人"飞"进眼镜——虚拟 ZETA 的形象诞生。这是一段预制的转场动画，把"一台机器人陪不了所有人"的限制，讲成一个动人的科幻设定。

技术灵魂 · 剧情护栏

如何让 Agent 自由聊但不跑偏

"骨架固定 + 话随人走"——预制剧情按时序照常播，Agent 在这条固定时间线上说话：科普不会讲错、话题不会跑飞、时长可控。

固定骨架（预制 · 不受 Agent 影响）
  • 时间线：机器人动作、MR 画面、灯光到点就播，Agent 改不了
  • 必讲知识点：本舱科普硬知识必须讲到（RAG 知识库保证准确）
  • 时序推进：到点自动进下一段，Agent 只在节点间隙说话，不卡流程
  • 节奏兜底：Agent 话说到时间就收，跟上预制时间线
自由血肉（LLM 按观众实时生成的语言）
  • 用观众的话与语气改写 ZETA 说话的风格
  • 顺着观众的反应，把这段故事往后多讲一点
  • 追问引导，帮观众自己想通
  • 把观众前面聊过的话，织进后面舱的对话

① 系统提示词

硬约束本舱知识点、说话边界，禁止编造月球常识、禁止声称能控制设备。

② 时序对齐

Agent 只读预制时间线的当前节点，在间隙里说话，绝不试图推进或改动演出。

③ RAG 知识库

科普知识存向量库，讲解从库中取，保证准确。

④ 兜底剧本

网络/模型故障退回预录台词，展览照常不中断。

一句话划清边界
MR 与机器人 全部预制、按时序自动播放。灯光、机器人动作、画面到点就演，跟 Agent 说什么无关。
ZETA Agent 只用语音/文字工作：把预制故事串起来、往后推、追问、答科普。不控制、不驱动任何硬件。
观众得到的 同一场固定的展，因为身边多了个会陪聊、会追问的搭档，每个人聊出来的都不太一样。
04 — 落地路径

一个月内跑起来

因为 Agent 只做语言层、不动任何现场硬件，落地极快。四周排期，直接对着展期倒排。

第 1 周 · 定内容

剧本与知识库

把四舱的预制时序拆出"节点表"（到哪一步 Agent 该说话），写四舱对话骨架 + ZETA 人设提示词，整理科普知识进 RAG 库。这周不碰代码，先把"说什么"定死。

第 2 周 · 搭通路

单舱 Demo 跑通

选生活舱：MR 眼镜里出 ZETA 形象 + 语音（ASR→LLM→TTS），读现场时序节点，在间隙开口。打通"听→想→说"闭环，延迟压到 1.5s 内。

第 3 周 · 铺四舱

四舱串联 + 兜底

四舱骨架全部接上，打通跨舱记忆与收尾回顾；配好断网/故障退回预录台词的兜底剧本，保证展览永不中断。

第 4 周 · 上现场

连调 + 彩排

设备批量到位、现场与预制时序对齐联调、多台并发压测、运营培训 + 全流程彩排。展期开幕即可用。
